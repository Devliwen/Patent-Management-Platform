# Postman 测试集合说明

本目录包含高校知识产权运营服务平台的 API 测试集合文件。

## 文件列表

- `patent-platform-collection.json`: 完整的 API 接口集合，包含认证、用户、机构、专家、专利、需求等模块。

## 导入与使用

1. 打开 Postman。
2. 点击左上角的 **Import** 按钮。
3. 将 `patent-platform-collection.json` 文件拖入或选择该文件。
4. 导入成功后，你会在 Collections 面板看到 **高校知识产权运营服务平台 API**。

## 环境变量

该集合内置了以下 Collection Variables（集合变量），你也可以创建 Environment（环境）来覆盖它们：

| 变量名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `base_url` | `http://localhost:8080` | 后端服务地址 |
| `token` | (空) | 登录后自动设置的 JWT Token |

## 快速开始

1. 确保后端服务已启动（默认端口 8080）。
2. 展开 **01. 认证模块 (Auth)**。
3. 执行 **用户注册** 接口（如果用户不存在）。
4. 执行 **用户登录** 接口。
   - **注意**：登录成功后，Postman 脚本会自动提取响应中的 `token` 并保存到环境变量中。后续所有需要鉴权的接口都会自动携带此 Token。
5. 现在你可以随意测试其他模块的接口了。

## 注意事项

- 部分接口（如审核、创建外部专利）可能需要管理员权限或特定角色，请根据业务逻辑调整数据库或代码中的权限校验。
- 所有的 `POST/PUT` 请求体均为 JSON 格式，你可以根据 `docs/api_v7_项目书全量接口文档.md` 修改参数。
